# 06-define-acceptance-and-rollback

## Purpose

Turn decisions into observable acceptance criteria and rollback conditions.

## Inputs

- change surfaces
- measurement
- risk

## Process

1. Convert each decision into an observable acceptance criterion.
2. Add executable/visual/external evidence type.
3. Define rollback.
4. Identify human gates for sensitive changes.

## Outputs

- acceptance criteria
- rollback plan
- human gates

## Test

A sensitive tracking change must include a gate/rollback instead of a vague “verify tracking”.
