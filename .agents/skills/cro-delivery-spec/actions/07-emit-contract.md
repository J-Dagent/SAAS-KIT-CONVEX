# 07-emit-contract

## Purpose

Emit the versioned Conversion Implementation Contract using the bundled template.

## Inputs

- all prior outputs

## Process

1. Fill the bundled contract template.
2. Keep machine-readable IDs/statuses stable.
3. Include evidence and blockers.
4. Avoid implementation prose that belongs to downstream code work.

## Outputs

- complete contract

## Test

A READY contract must have no silent nulls for implementation-critical decisions.
