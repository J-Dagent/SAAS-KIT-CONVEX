# 01-inspect-contract-and-repo

## Purpose

Read the implementation contract, AGENTS.md and affected code before editing.

## Inputs

- READY contract
- repo

## Process

1. Read AGENTS.md and the contract.
2. Inspect affected routes/components/tracking/server/data seams.
3. Identify reusable patterns and tests.
4. Confirm scope/risk before edits.

## Outputs

- implementation context
- existing seams
- risks

## Test

If the contract is not READY for the requested surface, stop that surface rather than guessing.
