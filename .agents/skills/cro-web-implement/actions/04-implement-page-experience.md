# 04-implement-page-experience

## Purpose

Implement approved page structure, copy, proof, CTA and responsive behavior with frontend autonomy.

## Inputs

- contract
- repo conventions

## Process

1. Implement the approved hierarchy and content.
2. Reuse or improve components based on repo evidence.
3. Preserve accessibility/responsive behavior.
4. Avoid unapproved strategic edits.

## Outputs

- code changes

## Test

Component boundaries may improve, but approved copy and CTA semantics must not change silently.
