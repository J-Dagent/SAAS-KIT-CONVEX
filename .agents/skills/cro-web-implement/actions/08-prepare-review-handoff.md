# 08-prepare-review-handoff

## Purpose

Summarize changed files, acceptance coverage, risks and remaining external checks for review/staging.

## Inputs

- checks
- contract

## Process

1. Map changes to acceptance criteria.
2. State tests run and results.
3. State external checks not run.
4. Hand off to code-review/cro-web-validate.

## Outputs

- review handoff

## Test

Never claim production deployment when the work only reached local/PR/staging readiness.
