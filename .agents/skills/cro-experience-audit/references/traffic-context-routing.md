# Traffic-context routing

Classify the acquisition context before judging the page.

| Context | Typical intent | Audit posture |
|---|---|---|
| Google brand | very high, often existing demand | isolate before claiming LP superiority |
| Google non-brand | high acquisition intent | inspect query → ad → hero → form → follow-up message match |
| Google local/programme intent | high and specific | expect route/page specificity, relevant proof, direct CTA |
| PMax | mixed/opaque | request cluster/query/asset context before strong conclusions |
| Meta cold | low to medium | inspect education, trust, risk, friction and qualification |
| Meta retargeting | medium to high | allow more direct action but preserve proof and attribution |
| Organic SEO | mixed | do not apply paid-page no-nav rules mechanically |
| Email/direct/warm | warm | optimize clarity and action, not paid-acquisition inference |

For search-led programme pages, audit message continuity through:
`query → ad → page/H1 → form expectation → thank-you/follow-up → sales reality`.
