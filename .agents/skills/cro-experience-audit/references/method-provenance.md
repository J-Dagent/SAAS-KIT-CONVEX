# CRO method provenance

This skill deliberately synthesizes multiple supplied methods. No single source is treated as universal truth.

## Source families

1. **COO landing-page CRO method**
   - context-first page diagnosis;
   - page type, awareness, traffic intent, offer, proof, CTA, form friction and CRM quality;
   - avoid inventing proof or forcing one page archetype onto every route.

2. **COO funnel CRO method**
   - evaluate funnel math and downstream quality, not only page CVR;
   - distinguish intent by acquisition channel;
   - protect friction that improves qualification, trust, operations, compliance or sales quality;
   - isolate root cause before changing the page.

3. **Supplied CRO masterclass: video + transcript + written synthesis + slides**
   - heuristic library for high-leverage landing-page tactics;
   - embedded/hero form, fewer paid-traffic escape routes, strong proof, objection handling, risk reversal, mobile CTA, speed and rapid follow-up;
   - search-intent route variants such as Service/Programme × Location/Context;
   - behavioral evidence and controlled experiments decide winners.

4. **Supplied traffic/Google CRO strategy**
   - classify acquisition context before judging the landing page;
   - preserve query/ad/page/form/follow-up message match;
   - do not apply paid-search rules mechanically to SEO, brand, warm or mixed-intent traffic.

5. **Supplied orchestration/handoff doctrine**
   - one decision owner;
   - evidence status: READY / NEEDS_EVIDENCE / UNKNOWN / BLOCKED;
   - strategy and measurement ownership remain upstream;
   - implementation, technical reliability and technical QA remain downstream;
   - every cycle should produce a learning or an explicit unresolved state.

## Integration rule

Use the sources as complementary layers:

`business context + downstream truth → traffic intent → message match → conversion heuristics → experiment design → structured handoff`

When sources conflict, prefer current first-party evidence and explicit owner decisions over generic heuristics. Never convert a source anecdote or claimed uplift into a guaranteed benchmark.
