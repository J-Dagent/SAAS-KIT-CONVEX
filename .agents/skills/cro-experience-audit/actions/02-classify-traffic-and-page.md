# 02-classify-traffic-and-page

## Purpose

Classify traffic intent, page type, funnel stage and conversion action before judging tactics.

## Inputs

- evidence inventory

## Process

1. Classify channel/intent without collapsing unlike traffic.
2. Identify page/funnel stage and realistic action.
3. Record any assumptions explicitly.
4. Load the relevant traffic-context reference.

Read `references/traffic-context-routing.md` before final classification.

## Outputs

- traffic context
- page type
- conversion goal
- intent assumptions

## Test

Google brand and Google non-brand must not be treated as equal-intent traffic.
