# 04-audit-conversion-architecture

## Purpose

Audit page hierarchy, action accessibility, proof, objections, mobile and performance using context-sensitive heuristics.

## Inputs

- page evidence
- traffic/page classification

## Process

1. Audit the rubric in priority order.
2. Apply source heuristics only when context fits.
3. Distinguish missing proof from weak presentation.
4. Record observable evidence for each issue.
5. Use `references/coo-cro-principles.md`, `references/masterclass-cro-heuristics.md`, and `references/audit-rubric.md`; treat tactics as hypotheses, not mandatory checklist items.

## Outputs

- issues by severity
- mechanisms
- candidate fixes

## Test

Do not fail an organic SEO page solely because it has navigation; explain context before applying paid-page heuristics.
