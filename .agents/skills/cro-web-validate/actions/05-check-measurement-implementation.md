# 05-check-measurement-implementation

## Purpose

Verify the specified events/IDs are technically emitted and routed, while keeping Measurement QA ownership separate.

## Inputs

- Measurement Contract
- runtime/tool evidence

## Process

1. Check event names/IDs against the Measurement Contract.
2. Verify browser/server emission technically.
3. Verify external destinations only with actual evidence.
4. Keep Measurement QA verdict separate.

## Outputs

- technical measurement result
- external verification gaps

## Test

n8n 200 does not prove a Google Ads or Meta CAPI receipt.
