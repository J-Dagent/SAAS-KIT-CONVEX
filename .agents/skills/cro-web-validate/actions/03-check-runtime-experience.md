# 03-check-runtime-experience

## Purpose

Validate responsive behavior, navigation/CTA behavior, accessibility basics and success routes in a real browser when possible.

## Inputs

- running app
- contract

## Process

1. Start the relevant app.
2. Use agent-browser when available.
3. Exercise desktop/mobile and keyboard/error/success paths.
4. Capture concrete evidence.

## Outputs

- runtime evidence

## Test

Do not use static code inspection as the only evidence when the app can be run.
