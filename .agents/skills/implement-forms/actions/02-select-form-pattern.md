# 02-select-form-pattern

## Purpose

Select Guide, Quiz, or Programme/Formation based on the approved path/behavior, without imposing visual structure.

## Inputs

- requirements
- repo context

## Process

1. Compare approved behavior with Guide/Quiz/Programme references.
2. Select one primary pattern.
3. Record deviations as configuration.
4. Do not infer visual design from the pattern.

## Outputs

- pattern decision
- required behaviors

## Test

A multi-step assessment with dynamic questions and final contact capture selects Quiz, not Programme.
